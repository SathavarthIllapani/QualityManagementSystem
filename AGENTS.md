# Repository Guidelines & Agent Instructions

## Git & Workflow Rules

- **Preserve Git History**: Avoid rewriting published git history (e.g., force pushing, rebasing, or squashing commits that have already been pushed to the remote repository).
- **Working State**: Always keep the branch in a working, buildable state before pushing commits.
- **Clean Commits**: Make atomic, well-described commits with clear messages summarizing the changes made.

## Development Standards

- **TypeScript**: Maintain strict typing and resolve all type errors before committing.
- **Code Consistency**: Follow established formatting and design patterns across the repository.
